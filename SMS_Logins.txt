SETUP ON A NEW MACHINE
1. Put the project in C:\xampp\htdocs\sms and start Apache + MySQL (XAMPP).
2. Create an empty database "smsDB" and import:  mysql -u root smsDB < database/smsdb.sql
3. Open http://localhost/sms/ and log in as admin.
4. Settings > Email Settings: enter Gmail address + App Password (blank in the dump).
   Settings > SMS Settings: enter Twilio details if WhatsApp/SMS is needed (blank in the dump).
